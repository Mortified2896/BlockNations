# Frozen-policy position probes

This development tool measures action preferences in synthetic legal positions or verified recorded games. It compiles the same C# rules, fair observation source and action schema used by the game and training worker. It neither trains a model nor changes an active run, reward, roster or release.

```sh
dotnet build Tools/PolicyProbes/BlockNations.PolicyProbes.csproj --configuration Release
Tools/PolicyProbes/bin/Release/net8.0/BlockNations.PolicyProbes --self-test
```

`positions.json` contains eight distinct positions, each copied into both seat perspectives and labelled with both starting roles: 32 fixtures, not 32 independent games. They cover visible city captures, visible ranged attacks, a threatened city, Archer movement after shooting, Warrior attacking after moving and a Rider with its attack already spent. Combat health uses the shared integer storage scale (10 units per displayed point).

These isolated fixtures have fresh observation memory and synthetic resource budgets. `positions_with_history.json` is a separate sensitivity set: own gold respects fourth-round income parity (1 for first, 0 for second), and explored tiles include a minimum hypothetical friendly path from the starting city. It uses no hidden enemy information. Neither set proves a complete reachable match history or reproduces a natural self-play distribution. Keep their receipts separate and check promising findings against full games or actual replay positions.

The compiled probe emits a source-selection row and conditional action rows. Only the existing 3,120-float vectors and 259-action masks reach frozen actor inference. Outcome labels are separate analysis data generated by applying legal commands to copies of the authoritative state. Hidden blockers are not guaranteed wins. Twelve checks include hidden-unit/resource/ID invariance, private enemy action budgets, ranged visibility, action-order constraints and disabled Scout recruitment.

Score a frozen candidate, using the existing local ML Python environment:

```sh
/Users/Jo/.local/share/blocknations-ml/venv/bin/python Tools/PolicyProbes/score_positions.py \
  --candidate-manifest /absolute/path/to/frozen/manifest.json \
  --probe /Users/Jo/GitHub/BlockNations/Tools/PolicyProbes/bin/Release/net8.0/BlockNations.PolicyProbes \
  --cases /Users/Jo/GitHub/BlockNations/Tools/PolicyProbes/positions.json \
  --root '/Users/Jo/Library/Application Support/BlockNations/Training' \
  --destination '/Users/Jo/Library/Application Support/BlockNations/Training/benchmarks/new-position-review.json'
```

The destination must be new and belong to the marked shared training root. Receipts share its 20 GB allowance and reserve, and include target rules, model/schema identity, frozen/source/input hashes and package versions. A v4-trained actor tested under core-three rules additionally requires `--candidate-transfer` with an explicit compatible source/target contract. Original training provenance is retained.

By default, score both `Policy` and `Hard`; repeated `--difficulty` options can select other existing inference modes. A macro action's joint probability is source-selection probability multiplied by its conditional action probability. End Turn includes its root probability and its conditional probability at every source. These are preference measurements, not win rates, Elo or evidence of useful full-game strategy. A compulsory legal choice mainly tests the mask. Low probability for a useful legal shot is a diagnostic; it does not establish the optimal longer plan, whether a unit is balanced or whether a network change would fix it.

Do not treat starting-role labels as extra inputs: schema v2 does not explicitly encode the first mover. Mirrored/role-labelled copies can therefore produce identical model inputs. Preserve their dependence when reporting evidence. The current feed-forward encoder also lacks enemy-unit observation history and an explicit `AttackEndsMovement` recruit capability. Position probes help test hypotheses for a separately versioned representation or training distribution; they do not silently change the current contract.

The scoring boundary, real compiled projection, provenance, mixed-rules rejection, protected output files and storage guard can be checked with:

```sh
/Users/Jo/.local/share/blocknations-ml/venv/bin/python -m unittest discover -s Tools/PolicyProbes -p 'test_*.py'
```

## Recorded full-game positions

`extract_replay_positions.py` accepts up to eight completed automated evaluation replays from the marked training root. It excludes human-match folders, symlinks, truncated histories, tactical curriculum openings, interrupted games and incompatible rules. The C# tool verifies every recorded transition by applying a fair legal command from the preceding state. It carries allocation counters through deaths and recruitment and reconstructs explored tiles using only each seat's own observations at macro-action boundaries. Public cities come from the standard opening. Descriptions and private world-state labels do not enter inference.

```sh
/Users/Jo/.local/share/blocknations-ml/venv/bin/python Tools/PolicyProbes/extract_replay_positions.py \
  --replay '<training-root>/benchmarks/<completed-evaluation>/workers/0/replays/recent-0.json' \
  --probe /Users/Jo/GitHub/BlockNations/Tools/PolicyProbes/bin/Release/net8.0/BlockNations.PolicyProbes \
  --root '/Users/Jo/Library/Application Support/BlockNations/Training' \
  --destination '<training-root>/benchmarks/<new-review>/cases.json' \
  --provenance '<training-root>/benchmarks/<new-review>/provenance.json'
```

Repeat `--replay` to add sources. The extractor selects up to 32 evenly spaced recorded positions with legal attacks or fully visible city-capture opportunities. Both output files must be new, bounded benchmark artifacts. Score them with the command above, additionally passing `--case-provenance <provenance.json>`. The scorer verifies the original replay, case and assembly hashes, preserves source/frame/recorded-candidate-seat links and reports joint ranged-attack probabilities. Attack distance is derived from the labelled board positions; the shared C# engine determines legality and outcomes.

These are diagnostic preferences in a small selected sample, not match win rates, a representative frequency estimate or independent balance games. Frames within one game are dependent, and separate traces may repeat deterministic lines. The sample can contain both the recorded candidate's and the reference opponent's positions; scores in reference-owned positions test generalization rather than the candidate's natural play distribution. A legal shot can compete with another useful action. Keep action alternatives and visible wins when interpreting a low shooting probability. Never feed these evaluation positions into training or change rewards to make them pass.

The self-test also creates a complete legal recorded game with a ranged opportunity and a visible city capture, and rejects altered resources, skipped transitions, truncated/unfinished histories, old rules and nonstandard openings. `--replay-fixture` emits that test fixture for the Python boundary checks; it is not a training scenario.
